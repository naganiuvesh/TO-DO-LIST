# Todo List App

A simple Todo List application built with HTML, CSS, and JavaScript.

## Features
- Add new tasks
- Delete tasks
- Mark tasks as complete
- Data saved in localStorage

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6+)
- localStorage API

## How to Use
1. Open index.html in browser
2. Type task in input box
3. Click "Add Task" or press Enter
4. Click "Complete" to mark as done
5. Click "Delete" to remove task
